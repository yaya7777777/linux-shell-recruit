# Task 02 Answer

请在这里回答题目中的两个问题。

### 1.为什么./tools/recruit-info可以运行，而直接输入recruit-info找不到它？

- ./tools/recruit-info是一个带路径的命令，./表示当前目录，Shell会直接去这个确切路径找文件并执行它，不会去查PATH
- 直接输入recruit-info时，Shell只在PATH环境变量列出的目录里查找当前目录，而.不在 PATH 中，所以找不到，会报错command not found

### 2.当我们输入ls时，Shell是如何找到对应程序的？

- Shell会遍历PATH环境变量里的每个目录，如/user/local/bin、/user/bin、/bin等（一般都是～/bin）

- 然后按顺序在每个目录中查找名为ls的可执行文件，找到第一个匹配的就执行它，比如/user/bin/ls。

- 可以用command -v ls查看实际解析到的路径
